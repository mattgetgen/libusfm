# `usfm` Command-Line Tool Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the x86-only benchmark in `main.c` with the `usfm` tool
described in `docs/superpowers/specs/2026-11-16-cli-design.md`: colored
USFM, tree and text views; chapter and verse references; a benchmark
mode; POSIX and Windows support.

**Architecture:** One C99 file, `main.c`, that uses only the public
`usfm.h` API. It has these sections:

| Section | What it holds |
| --- | --- |
| Platform | the only `#ifdef _WIN32` code |
| Input | reading files and stdin |
| Output | writing to stdout, with optional color |
| Tree helpers | marker names and end markers read from the source |
| Walk | the iterative preorder walk over a node range |
| USFM, tree and text views | three callback sets for the walk |
| References | parsing a REF and resolving it to a node range |
| Diagnostics and benchmark | `-d` output and `-b` timing |
| Main | argument handling and the per-input loop |

A shell script runs golden-file and behavior tests.

**Tech stack:** C99, bash, gcc/clang (ASan + UBSan in debug), and
`zig cc` to cross-compile for Windows.

**Status:** while planning, the whole tool was prototyped and verified
in `/tmp/cliprobe/`:
- `main.c` (1,044 lines);
- `tests/cli_test.sh`;
- `tests/cli/sample.usfm`;
- `tests/cli/expected/*.txt` (17 golden files, reviewed by eye).

On that prototype:
- `tests/cli_test.sh` passes 41 of 41 against the WEB corpus under ASan
  and UBSan;
- `clang -O3 -Werror` builds it;
- `zig cc` compiles it for `x86_64-windows-gnu` and `aarch64-macos`.

The tasks below move it into the repository in reviewable steps. The
prototype files are the source of truth for code; this plan does not
repeat the 1,044 lines.

### Task 1: Record the prototype's changes to the spec

Building the prototype changed six details of the approved design.

**Files:**
- Modify: `docs/superpowers/specs/2026-11-16-cli-design.md`

- [ ] **Step 1: Edit the spec**

  - **USFM view, closers:** write an end marker only where the source
    had one, copied verbatim (`\w*`, `\+w*`, `\*`, `\esbe`). Footnote
    parts such as `\fr` and `\ft` are not closed in the source. Closing
    them anyway would print `\fr 1:2 \fr*`, which is valid but noisy.
    Either way the output parses back to the same tree.
  - **USFM view, line breaks:** `\v` also starts a new line, the usual
    USFM layout. The parser drops that newline when it reads the text
    back, so the tree is unchanged. A cell marker (`\tc2`) is preceded
    by a space, because the parser trims the space at the end of cell
    text. ATTRIBUTES spans already include the `|`.
  - **USFM view, stability:** on the sample the view prints the input
    byte for byte. On every corpus file, printing its own output again
    gives identical output.
  - **References:** trailing nodes with none of their content selected
    are dropped from a range. A verse ends at the next `\v`, which
    otherwise drags in the opening of the next paragraph.
  - **Text view:** cells are separated by a TAB. A verse number gets a
    space before it unless it starts the line. Figure captions are kept.
  - **Benchmark:** the AST is freed after each pass, outside the timed
    region. Not freeing would keep N whole trees alive (about 6 GB for
    100 passes over WEB-STRONGS).
  - **Golden file names:** `.` replaces `:` (`usfm-1.3-5.txt`), because
    Windows can't check out file names with `:`.

- [ ] **Step 2: Commit**

```bash
git add docs/superpowers/specs/2026-11-16-cli-design.md
git commit -m "docs: CLI spec details settled while prototyping"
```

```markdown
## Command-line tool

`./build.sh release` builds `./usfm`, a small reference tool built on the
public API (`main.c`):

    ./usfm GEN.usfm              # colored USFM
    ./usfm -t GEN.usfm 1:3       # the AST of Genesis 1:3
    ./usfm -x books/ "JHN 3:16"  # plain text, from a directory
    ./usfm -b 100 books/         # parse speed

Run `./usfm -h` for every option.
```
